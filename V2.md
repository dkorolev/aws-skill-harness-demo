# awsw v2

The supported v2 is the Rust implementation in [`v2/`](v2/README.md). Run it from the repository root:

```sh
./awsw-v2 whoami
./awsw-v2 --region us-west-1 ec2
./awsw-v2 --json discover
```

For architecture, credentials, protocols, commands, testing, threat model, and the enclave migration plan, read [`v2/README.md`](v2/README.md) and [`v2/ARCHITECTURE.md`](v2/ARCHITECTURE.md).
