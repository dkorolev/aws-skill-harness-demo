# awsw v2

The supported v2 is the Rust implementation in [`v2/`](v2/README.md). Run it from the repository root:

```sh
./awsw-v2 whoami
./awsw-v2 --region us-west-1 ec2
./awsw-v2 --json discover
```

The original implementation is retained temporarily as an explicit reference artifact:

- `awsw-v1-obsolete`: original AWS CLI-backed program.

The obsolete program is not launched by `./awsw-v2`. For architecture, credentials, protocols, commands, testing, threat model, and the enclave migration plan, read [`v2/README.md`](v2/README.md) and [`v2/ARCHITECTURE.md`](v2/ARCHITECTURE.md).
